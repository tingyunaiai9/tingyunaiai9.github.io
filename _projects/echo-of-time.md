Echo of Time is a three-player cooperative puzzle game developed with Unity and C# for a software engineering course project. The game focuses on cross-time collaboration: players coordinate actions across different temporal states to solve spatial and logical puzzles.

The project received first prize in the 2025 Software Innovation and Creativity Competition, an award in the game track of the TCA Unlimited Creation Competition, and third prize in the 9th Tsinghua Software Design Competition.

**Keywords:** Unity, C#, cooperative gameplay, puzzle design, interaction design.
